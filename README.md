# 刷题机（静态站点）

## 打开方式
- 在线：直接打开部署地址即可使用，无需安装。
- 本机：用任意静态文件服务器把本目录起在本地端口访问亦可。

## 加到桌面 / 主屏幕
- 手机浏览器菜单里选「添加到主屏幕」；电脑浏览器在地址栏右侧选「安装 / 创建快捷方式」。

## 进度存在哪里
- 答题进度只保存在当前浏览器的本机存储（localStorage）里，不会上传到任何服务器；换浏览器、清除站点数据后进度会丢失。
- 换设备或重装前，用菜单里的「导出进度」保存 JSON；在新环境用「导入进度」合并恢复。

## 离线使用
- 首次打开需联网加载章节；点头部菜单里的「缓存全部」，等待提示「已可离线使用」后，已缓存章节在断网时仍可作答。
- 未访问、也未被全部缓存的章节，断网打开会提示本章未缓存，需联网后再进。

## 说明
- 本站不接入统计、云同步或广告。
